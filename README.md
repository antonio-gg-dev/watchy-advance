# Watchy Advance

Watchy Advance is an open-source operating system for Watchy V3.

> [!WARNING]
> Watchy Advance is currently under active development and is not ready for daily use.

The goal is to provide a simple, modular and extensible foundation for building watchfaces and applications on Watchy V3.

## Planned features

- Build-time configuration for system features and components
- Multiple selectable watchfaces with support for custom ones
- Applications with power-efficient background events
- Support for custom applications
- Centralized notification system
- Native desktop simulator
- Developed entirely using TDD
